Making it yours

Theme Colours, glow, brightness and how much moves. Presets get you close in one click, then everything stays editable. Nothing here can break the layout, and Reset puts it back.
Alerts Each type — follower, sub, donation, bits — has its own wording, timing, size, place on screen and look. Text uses tags like {name} and {amount}, filled in when the alert fires. Effects like glow, RGB split and scanlines are switches, and Test Alert shows the result.
Chat and Goals Font, size, colours, where they sit and which parts show. Goals can run across or upright.
Basic vs Advanced Each page shows the everyday controls first. Anything marked ADVANCED is folded away until you want it — you never have to use it.
If OBS is working hard Theme → Effect performance → LOW turns off the expensive effects, and Motion → Reduced stills everything except the live dot.
Undo anything Every control has a small ↺ to reset just that one. Each card has RESET, and Integrations has a full reset. Your uploaded images are never removed by a reset — only the Clear button on Branding does that.

Your own artwork — optional

Drop files into the assets folder mascot.png · avatar.png · logo.png · starting-background.jpg · brb-background.jpg · ending-background.jpg
Use those exact names and they replace the placeholders automatically. The package looks finished without them, so there is no rush.

If something looks wrong

All the overlays are blank The server isn't running. Double-click Server Status.bat — it will tell you, and Start Server.bat starts it again.
One overlay looks stale or frozen Right-click that source in OBS → Properties → Refresh cache of current page.
The camera doesn't line up with its frame Undo any manual resize (Ctrl+Z). The scene collection already places it exactly; dragging it by hand is what knocks it out.
