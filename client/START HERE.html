All six scenes appear, already sized and positioned. Nothing to drag.

2

Open the JON · 2 Gameplay scene, double-click Camera — Gameplay, and choose your webcam from the Device list. Click OK.

Do the same in JON · 3 Just Chatting. The size, position and rounded corners are already set — only the device is missing.

3

Open the control panel

http://127.0.0.1:8787/control.html

Start and stop the stream clock, set today's topic, move the goals, fire test alerts, and turn modules on and off. Everything updates on stream instantly.

If something looks wrong

All the overlays are blank The server isn't running. Double-click Server Status.bat — it will tell you, and Start Server.bat starts it again.
One overlay looks stale or frozen Right-click that source in OBS → Properties → Refresh cache of current page.
The camera doesn't line up with its frame Undo any manual resize (Ctrl+Z). The scene collection already places it exactly; dragging it by hand is what knocks it out.
Everything runs on this PC. Nothing is uploaded, no account is needed, and the server only listens to this machine.
