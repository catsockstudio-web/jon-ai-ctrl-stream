Before you start

You need OBS Studio and a Windows PC. Everything else is in the folder you were given. The package installs one small helper (Node.js) the first time you run Setup, and nothing else.

Nothing leaves your computer. The overlay is served by a small program running on your own PC at an address only your PC can reach. There is no account to make, no monthly fee, and no data sent anywhere.
SECTION 1

Setting up

Three steps. You do this once.

  1. Unzip the folder somewhere permanent. Your user folder is ideal — for example C:\Users\YourName\Nightwire. Do not run it from inside the ZIP, and do not leave it in Downloads where it may be cleaned up.
  2. Double-click Setup.bat. It checks for Node.js and installs it if needed, starts the overlay server, sets it to start automatically when you sign in, and opens the dashboard in your browser. Say yes to any Windows permission prompt — that is the Node.js installer.
  3. Leave it alone. From now on the server starts by itself at sign-in. You never need to open a terminal or type a command.

The other buttons in the folder

FileWhat it does
Setup.batFirst-time install. Safe to run again if something breaks.
Start Server.batStarts the overlay and opens the dashboard.
Stop Server.batStops the overlay. Your settings are kept.
Server Status.batTells you whether it is running, and on what address.

The dashboard address

The dashboard lives at http://127.0.0.1:8787/dashboard.html. Bookmark it. That address only works on this PC — that is deliberate, and it is what keeps your controls private.

You can open the dashboard in three places. A normal browser window on a second monitor; a dock inside OBS (View → Docks → Custom Browser Docks); or both at once. They all control the same overlay, because the settings live in the server rather than in any one window.
SECTION 2

Adding the overlay to OBS

The fast way takes about a minute and wires up all six scenes for you.

The fast way — import the scene collection

  1. In OBS, choose Scene Collection → Import.
  2. Pick obs\Nightwire.json from the package folder. Every scene, browser source, size and position comes in already set up.
  3. Switch to the imported collection under Scene Collection.
  4. Add your camera and game capture. These are the only two things the import cannot create, because only you know which devices they are. Put both below the overlay in the source list, with the camera above the game capture — top to bottom that is Overlay, Camera, Game Capture.
Order matters — three layers, in this order top to bottom: Overlay, Camera, Game Capture. The overlay goes on top; the camera opening is a genuine transparent cutout, so the camera shows through it while the frame and nameplate stay drawn over it. The camera itself must sit above the game capture, because game capture is a full-screen, opaque source — if it is listed above the camera it will cover the camera completely wherever the two overlap. If you put the camera above the overlay, it will cover the frame instead.

The manual way — one browser source per scene

If you would rather build your own scenes, add a Browser source in each one, set it to 1920 × 1080, and paste the matching address. The OBS Setup page in the dashboard has a copy button beside every one of these.

Browser source settings

  • Width 1920, Height 1080 for every scene source.
  • Leave Shutdown source when not visible off, so a scene is ready the moment you cut to it.
  • Leave Refresh browser when scene becomes active off — changes arrive on their own.
  • Do not tick Control audio via OBS. The overlay makes no sound.

SECTION 4

The dashboard

One page, two halves. The left half is what you are looking at. The right half is what you are changing. They work independently.

Left — the preview

The numbered buttons under the preview choose which scene you are looking at. This is only a viewer; it does not change what OBS is showing. The chequerboard is transparency — that is where your game and camera show through.

The four buttons marked DEMO DATA put fake activity on screen so you can see your settings working: a test alert, a chat message, some progress on a goal.

The demo buttons reach your real overlay. They are not sandboxed to the preview — a test alert plays on every open OBS source, including on stream. Use them while setting up, not while live.

Right — the pages

The tabs across the top choose what you are editing. Most settings are global: an alert looks the same on every scene, and a colour change applies everywhere. Only the Scenes page is tied to the scene selected on the left.

Every page puts the everyday controls first. Anything folded under ADVANCED is optional — you never have to open it.

Changes are instant and permanent. There is no Save button. Every change reaches OBS the moment you make it, and is remembered after a restart.
SECTION 5

Two things that will save you time

Read this before you start changing settings. Both answer the same question: is this control broken, or am I looking in the wrong place?

The i button

Every control has a small i beside it. Press it and an explanation appears in the panel under the preview — what the control changes, and, where it matters, what it does not.

That second half is the important one. Most settings only show up in certain places. Chat position does nothing on the BRB card, because BRB has no chat. Background brightness does nothing on Gameplay, because Gameplay is transparent. Half the recent-events controls do nothing while Activity is set to TILES. None of that is broken — but you cannot tell by looking, so the i tells you.

LIVE and PREVIEW

The switch under the scene buttons decides where your changes go.

ModeWhat happens when you change something
LIVEIt reaches OBS immediately. This is the normal setting.
PREVIEWIt shows in the preview only. OBS keeps showing what it showed before.

In PREVIEW, two buttons appear. PUSH TO LIVE sends everything you have changed to OBS in one go and returns you to LIVE. DISCARD throws it away.

This is how you redecorate mid-stream. Switch to PREVIEW, change as much as you like, check it in the preview, then push when you are happy. Your audience sees one clean change instead of watching you try eleven colours.
The demo buttons follow the same rule. In PREVIEW, Test Alert plays in the preview only — nobody watching sees a fake follower. In LIVE, it plays on your real overlay, so save it for before you go on.
SECTION 7

Live Control

The page you keep open while streaming. Four cards.

Session

START STREAM tells the overlay you have gone live. It turns the status dot green, starts the uptime clock, and begins caffeine decay if you use it. It does not start your OBS stream — you still do that in OBS. Once you are live the button reads RESTART STREAM; pressing it sets the clock back to zero. END returns you to offline.

Today's topic and Now playing appear on the overlay as you type. Countdown sets the timer on the Starting Soon card, in minutes. Leave it blank for no countdown.

Caffeine

A running joke that doubles as a stream-length indicator. Set the level and which cup you are on. Auto-decay makes it fall gradually as the stream runs, so you do not have to touch it.

Goals

Current and target for followers, subs and the coffee fund. The goal rail across the bottom of the Gameplay scene follows whichever goal you nominate on the Widgets page.

Fire an Alert

For when something actually happens and you want to acknowledge it by name. Type the name, and an amount or tier if it applies, then press the matching button. This also updates the activity tile for that type on the Gameplay scene.

ButtonAlso updates
FOLLOWERThe follower tile
SUBThe sub tile
DONATIONThe coffee-fund tile
BITSNothing — alert only
Fire an Alert vs Test Alert. Fire an Alert uses the name you typed and updates the tiles. Test Alert, under the preview, uses made-up demo details and changes nothing else — it is for checking how an alert looks while you design it.
SECTION 7

Theme

The look of the whole package, in one place.

Presets

Six one-click looks. A preset sets the colours and leaves everything else alone, so it is a starting point rather than a reset — change any colour afterwards and your change sticks.

Colours

Primary is the main accent, used for the brand bar, borders and most glows. Secondary is the contrast accent, used for live indicators and goal fills. Highlight is for money — tips and the coffee fund. Background and text colours are under ADVANCED and rarely need changing.

Feel

ControlWhat it does
Glow intensityHow much everything glows. 0 is flat and clean; 2 is heavy neon.
Background brightnessHow dark the full-screen cards are.
MotionFull is everything. Reduced stills most animation. Off stops all of it.
Effect performanceCaps how expensive the alert effects are allowed to be.
If OBS is working hard, set Effect performance to LOW and Motion to Reduced. That switches off the costly effects while keeping the glow, so it still looks like your overlay rather than a broken one.
SECTION 8

Branding

Your own artwork. Every slot is optional.

The package is designed to look finished with no artwork at all — every slot has a built-in placeholder drawn in code. Adding your own is an upgrade, never a requirement.

Drop a file on a slot or click it to browse. It is copied into the package and remembered. Clear puts the built-in placeholder back.

PNG, JPEG or WebP, up to 8 MB. PNG with transparency is best for logos.

Artwork appears straight away. You do not need to restart the server, reload a browser source, or touch OBS at all — drop the file on a slot and the scenes already open in OBS pick it up within a second. Clear takes it back off the same way.
Your uploads are safe from resets. No reset button removes artwork — not even Reset everything. Only the Clear button on the slot itself deletes a file.
SECTION 9

Scenes

The wording on the full-screen cards.

This is the one page tied to the scene selected in the preview. Pick a scene on the left, and the fields here change to that scene's wording — headline, sub-line, schedule, tagline.

Sizes and positions are part of the design and are not editable. That is deliberate: it is what stops the package from being broken by accident. Long text shrinks to fit rather than overflowing.

SECTION 10

Alerts

Six types, each with its own wording, timing, position and effects.

Wording

Alert text uses tags that get filled in when the alert fires:

TagBecomes
{name}The person's name
{amount}The tip amount or bit count
{message}Their message, if any
{tier}Sub tier
{count}Raid viewers, or number of gift subs

So a title of COFFEE FUND · {amount} becomes COFFEE FUND · $5.00. A tag you mistype is left on screen as written rather than vanishing, so you can see the error.

Timing, size and position

Duration is how long the alert stays up. Scale makes it bigger or smaller — the package will not let you scale it off the edge of the screen. Position is a nine-square grid; placement is preset-only, which is what guarantees nothing ends up half off-screen.

Elements

Switch off any part you do not want: the icon, the label, the name, the amount, the message, the border, or the whole panel behind it. Turning the panel off gives you floating text with no box.

Effect stack

Nine effects you can stack. Each has its own settings.

EffectCost
Glow / BloomLow — always on, whatever the performance setting
Edge Trace, Flicker, ScanlinesLow
RGB Split, Ghosting, VHS SliceMedium — needs BALANCED or HIGH
CRT Distortion, NoiseHigh — needs HIGH

If you switch on an effect your performance setting does not allow, the page tells you why it is not running rather than silently ignoring it.

SECTION 11

Chat

Newest messages are at the top; older ones fade out beneath. Set the font, size and weight, how many messages show at once, and whether badges and timestamps appear.

Ground decides what sits behind the messages — a panel, individual bubbles, or nothing at all for text straight over your game.

Username colour offers a different colour per person, one accent for everyone, or plain theme text.

SECTION 10 · CONTINUED

Goals

Each goal can run across or upright, and can be drawn as a thin rail, as segments, or as the coffee mug. Turn off any part — label, value, target, percentage, icon.

Numbers themselves live on Live Control, so you are not digging through the customiser mid-stream to update a follower count.

SECTION 12

Widgets

Where each piece sits, and how big it is.

Each widget can be switched off, moved to one of nine preset positions, and scaled within a safe range. There is no free dragging — presets keep safe margins so nothing ends up under a Twitch overlay or off the edge.

The camera frame cannot be moved or scaled. Its opening is a transparent cutout at an exact position. Moving it would leave your camera out of register behind it, so the control is deliberately not offered.

Recent events

Set Activity → Mode to Recent events and the three tiles become a running list of who just followed, subbed, tipped, cheered or raided. Choose how many show and which kinds count.

The list covers the current session only — it is never written to disk, so restarting starts it fresh rather than replaying yesterday.

SECTION 13

OBS Setup page

Keep this page open while you build scenes by hand. It lists every scene and every individual widget, with the exact width and height to give each browser source.

The individual widget addresses are there if you want to build your own layout rather than use the full-scene overlays — for example, chat on its own in a corner of a scene you designed yourself.

SECTION 14

Connecting Twitch or YouTube

Optional. Everything works by hand without this — connecting just means you stop typing names in.

What each one gives you

SourceSupplies
TwitchFollows, subs, resubs, gift subs, cheers, raids, chat, and live status
YouTube LiveLive chat, Super Chats, memberships, and live status
RelayAnything else that can send a message — see below
ManualEverything, by hand. Never switched off.

Connecting

  1. Press CONNECT on the source you want.
  2. A short code appears. Open the address shown — for Twitch that is twitch.tv/activate — and type the code in.
  3. That is it. The page changes to CONNECTED by itself. You do not need to come back and press anything.
You are never asked for your password. You type a short code on the platform's own website, and it hands back permission. This package never sees your Twitch or Google password, and the permissions it asks for are read-only — it cannot post, ban, or change anything on your channel.

What changes once you are connected

Alerts fire on their own. Chat fills in by itself. The uptime clock starts when you go live and stops when you end, so you no longer press START STREAM.

Some fields on Live Control grey out — your follower count, for example. That is deliberate: while Twitch is reporting a number, letting you type over it would be a lie, because the next event would overwrite whatever you typed. Disconnect and they become editable again.

YouTube has no follower alert. YouTube does not publish subscriptions live, so there is nothing to listen for. Super Chats, memberships and chat all work. This is a YouTube limitation, not a missing feature.

The Relay — everything else

The relay is a local address that any other tool can send events to: Streamer.bot, StreamElements, Streamlabs, a Kick bridge, a Stream Deck button, or a script you wrote. If it can send a web request, it can drive your overlay.

The address is on the Integrations page, ready to copy. Anything sent to it appears exactly as if it came from Twitch. NEW ADDRESS changes the key, which stops any tool you set up earlier until you paste the new one in.

Signing out

DISCONNECT forgets the account. Note that Reset everything does not sign you out — settings and accounts are kept separately on purpose.

SECTION 15

Undoing changes

Three levels, smallest first. You cannot get permanently lost.

ControlUndoes
The small ↺ beside a settingThat one setting
RESET on a cardEverything on that card
Reset everything on IntegrationsAll settings — but never your uploaded artwork
Your artwork is never removed by a reset. Only the Clear button on an individual Branding slot deletes a file.

If a reset button seems to do nothing

The dashboard will tell you. If the overlay server is running an older version than the files on disk — which happens after an update, because the server keeps running from when you signed in — a yellow banner appears across the top of the dashboard telling you to restart it. Run Stop Server.bat, then Start Server.bat.

SECTION 16

Going live — checklist

  1. Check the dashboard says SERVER LINKED. Top right. If it says unreachable, run Start Server.bat.
  2. Check the switch says LIVE, not PREVIEW. In PREVIEW your changes are held back from OBS on purpose. Push them, or switch back.
  3. Turn off the setup aids. On the Widgets page, switch off Sample gameplay plate and Safe-area guides if you used them for positioning.
  4. Set today's topic and what you are playing. Live Control, top card.
  5. Update your goal numbers. Live Control, Goals card.
  6. Start your stream in OBS.
  7. Press START STREAM on the dashboard. This starts the uptime clock and turns the status dot green. Skip this if you have connected Twitch or YouTube — they tell the overlay you are live on their own.
Do not press the DEMO DATA buttons once you are live. Test Alert, Add Chat and + Goal all reach your real overlay, and your viewers will see them.

When you finish

Press END on Live Control to go back to offline, and switch OBS to the Offline scene. Leave the server running — it costs nothing and will be ready next time.

SECTION 17

If something looks wrong

The overlay is blank in OBS

Right-click the browser source and choose Refresh. If it is still blank, check the server is running with Server Status.bat. A source that fails will normally display the reason on screen rather than going blank, so read what it says.

My camera is covered by the overlay

The camera source is above the overlay in the source list. Drag it below. The overlay has a transparent hole cut for it and is meant to sit on top.

My camera is covered by my game capture

On the Gameplay scene, game capture is a full-screen, opaque source. If it is listed above the camera, it hides the camera wherever the two overlap. Drag the camera above the game capture — the source list should read Overlay, then Camera, then Game Capture, top to bottom.

The dashboard says SERVER UNREACHABLE

Run Start Server.bat. If it says the port is already in use, the server is already running — refresh the dashboard instead.

A button does nothing

Look for a yellow banner at the top of the dashboard. It means the running server is older than the files on disk, and it will tell you to restart. Run Stop Server.bat then Start Server.bat.

Text is overflowing or the font looks wrong

The package uses three web fonts and falls back to system fonts if it cannot reach the internet. Headlines shrink to fit rather than overflowing, so it will still be readable — it will just look slightly different until you are back online.

Alerts are stuttering

Theme page: set Effect performance to LOW and Motion to Reduced. If it persists, your OBS canvas may be running at a higher resolution than your PC can encode comfortably — that is an OBS setting, not an overlay one.

A control seems to do nothing

Press the i beside it. Most settings only apply in certain places, and the explanation says where — chat settings do nothing on a card with no chat, background brightness does nothing on the transparent scenes, and the recent-events controls do nothing while Activity is set to TILES.

Then check the switch above the demo buttons. If it says PREVIEW, your changes are being held back on purpose and only the preview is showing them. Press PUSH TO LIVE, or switch back to LIVE.

I connected Twitch but nothing happens

Check the Integrations page says CONNECTED rather than WAITING — if it still says waiting, the code was never entered, so press Connect and try again. If it says PROBLEM, the message underneath names the cause. A source can also be connected but missing one kind of event, which it will say in the same place; that means a permission was not granted, and disconnecting and reconnecting fixes it.

Starting over

Integrations page, Reset everything. Your uploaded artwork survives. If the package itself seems damaged, re-run Setup.bat.
