AFTER AN UPDATE

Your settings reach OBS the moment you change them — there is nothing to refresh for those. This is only for when a new version of the overlay itself is installed: a page that is already open cannot pick up new code by itself.

Leave OBS's own Refresh browser when scene becomes active unticked. It reloads on every cut to solve a problem that only happens after an update, and costs a visible flash each time you switch scenes.

CAMERA PLACEMENT

Order, top to bottom: Overlay, then Camera, then Game Capture. The overlay has a transparent opening the camera shows through, and game capture is full-screen and opaque — placed above the camera it hides it completely. On Gameplay, add an Image Mask/Blend filter (Alpha Mask) pointing at obs/camera-mask-gameplay.png so the corners match the frame.

WHICH COPY IS RUNNING

The folder this server is serving from. If you have just installed an update and nothing changed, check this is the folder you extracted into — a server left running from an older copy keeps the port, and every page carries on being served the old code.
